# sscs-chipathon-docs

## Contribution from a Collaborator

- `git clone git@github.com:sscs-ose/sscs-chipathon-docs.git`
- `git checkout -b mybranch`
- Make contribution
- `git commit -m "comment" -a`
- `git push -u origin mybranch`
  - add the apprpriate ssh identity (eg. silicon-vlsi) before pushing
- Go to GitHub.com, create pull request and merge the request
