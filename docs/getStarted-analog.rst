Analog Design
=============

Some quick resources to get you started doing analog design, simulation
and layout using **xschem**, **ngspice**, **magic**, and **klayout**

-  **xschem** and **ngspice**: Schematic editor, simulator and plotting
   tool.

   -  3-part video tutorial using *xschem* and *ngspice* with *GF180MCU*
      PDK. ( `Part-1 <https://youtu.be/MdywD87-DVg>`__ \|
      `Part-1 <https://youtu.be/DLvZSsLAbho>`__ \|
      `Part-3 <https://youtu.be/nBnR8Nm_B_I>`__ )
   -  `Analog design flow with opensource
      tools <https://unic-cass.github.io/training/analog-flow.html>`__:
      Online tutorial from `IEEE UNIC
      CASS <https://unic-cass.github.io/>`__ with detailed step-by-step
      instructions.
